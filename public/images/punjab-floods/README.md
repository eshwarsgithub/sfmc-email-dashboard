# Punjab Floods 2025 Images

This folder contains images related to Punjab floods 2025 for the relief donation website.

## Image Sources
- All images should be from verified sources showing Punjab flood impact
- Include proper attribution for each image
- Ensure images are optimized for web use (compressed for fast loading)

## Usage
Images are referenced from the React components using the public path:
`/images/punjab-floods/filename.jpg`
